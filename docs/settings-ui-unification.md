# 设置页视觉统一

日期：2026-09-25

## 目标

把参考图中的版式作为整个设置区的共同视觉基准：右侧内容列居中并限制最大宽度；页面标题、分组标题、行标题、说明文字共用字号与间距；设置项以标题和说明在左、控件在右的行形式呈现；相关设置项放进分组标题下方的浅边框圆角容器。窄窗口时自动改为上下布局。维护者在公共层调整一次即可覆盖所有设置页，不需要逐页维护字体、间距或控件宽度。

## 实现

- `ui/src/features/panels/settings/SettingsTheme.tsx` 是唯一视觉配置入口：`SETTINGS_VISUAL` 集中管理 960px 内容宽度、页边距、字号、分组/行间距、行内边距及窄/中/宽控件宽度；`SettingsThemeProvider` 为设置区域内的 antd 组件及其弹层提供局部 `ConfigProvider` 与 `App` 上下文。
- `SettingsForm`、`SettingsFormItem`、`SettingsSection` 提供共享表单、表单行和分组表面。原有表单字段值、保存与即时生效逻辑仍由各页负责；`extra` 说明统一呈现在字段标题旁，校验提示仍由 antd 放在控件附近。
- `ui/src/features/panels/settings/settings-theme.css` 统一处理居中内容列、行分割线、边框卡片、控件宽度、集合行、弹框和主题预览缩略图；内容列宽小于 680px 时表单行改为纵向排列。
- 设置页、供应商设置页、关于页和字体/外观页接入共享包装。外观页的系统/浅色/深色选择使用可视预览卡；供应商集合不再各自定义最大宽度。搜索及外部跳转沿用既有设置项锚点定位与高亮。
- 外观页顺序为界面语言、主题、字体；主题预览铺满卡片，不显示额外说明。字体输入占设置行的一半宽度，两种字体的预览各自紧跟对应输入框。共享表单关闭自动冒号，字体说明仅提示回车生效。
- 界面语言项说明其影响的是界面显示语言；字体说明与右侧输入区在左右布局时留公共行间距，窄屏上下堆叠时由同一断点规则留白。
- 模型与供应商页沿用外观页的分组标题、圆角卡片、字号与间距；AI 回复语言归入「通用」分组，供应商标题旁提供主要添加入口，卡片行展示协议、地址和模型能力摘要，编辑与删除操作均使用图标加文字。
- 旧的纵向表单视觉约定仅作为历史记录保留；新的布局契约由 `settings.style.test.ts` 和设置弹窗 smoke test 守护。

## 验收重点

1. 十个设置页面的内容列宽、页面标题、表单行标题与说明、控件高度和宽度档位一致。
2. 有分组的表单呈现相同的标题间距、卡片边框、圆角和内边距；普通设置项也归入共享行样式。
3. 窄窗口布局不溢出，设置行改为说明在上、控件在下；MCP 参数编辑器继续使用标签在上方的结构。
4. 搜索结果与外部设置跳转仍能定位到正确的设置行；保存、取消、脏状态、验证错误和即时生效行为保持原有语义。
5. 字体选择仍使用 `--ws-font-sans` / `--ws-font-mono`，主题色由现有 `--ws-*` token 提供；公共样式不硬编码应用强调色或字体链。

## 验证

执行 `pnpm --dir ui test`、`pnpm --dir ui run lint`、`pnpm --dir ui build`，并执行 `antd lint ./ui/src/features/panels --only deprecated --format json` 检查面板内的 antd 弃用项。

手动界面验证（仓库约定由用户完成）：

1. 打开设置，依次查看十个页面，确认内容列居中且标题、分组、行和说明文字的层级一致。
2. 查看「界面」页的系统、浅色、深色预览，切换主题与两类字体，确认即时生效和重启持久化。
3. 检查网络、安全、MCP、技能、工作区与智能体、供应商和关于页中的开关、选择器、输入框、长说明及列表操作。
4. 缩窄窗口，确认表单从左右排列切换为上下排列，控件和列表不横向溢出。
5. 使用设置搜索以及供应商详情跳转，确认滚动和短暂高亮覆盖整行。
6. 修改可保存设置后分别测试保存、取消、校验错误和离开未保存提醒。
7. 查看模型与供应商页，确认「通用」和供应商分组与界面页一致，添加入口位于供应商标题旁，模型行显示上下文/输出上限与输入能力，窄窗口下卡片不溢出。
