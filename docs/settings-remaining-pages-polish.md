# 其余设置页的视觉统一

2026-09-26。以设置页共用的 `SettingsThemeProvider`、`SettingsSection`、`SettingsFormItem` 为基准，收敛此前尚未整理的「写入后检查与校验」「技能」「工作区与智能体」「日志」「关于」。本批只调整信息层级、排版、字号和控件位置，不改变配置字段、保存边界或 IPC 行为。

## 方案与落地

- 写入后检查：开关及其说明回到标准表单行；命令使用宽控件列；超时与输出尾字符各用完整表单行，避免在半宽网格中再次压缩输入框。
- 技能：使用共用分组标题和卡片。名称与来源同一行，说明和适用场景分层显示；长文案截断后仍可通过标题查看全文。开关与带文字的删除动作集中在行尾，删除确认按钮使用危险色。
- 工作区与智能体：为命令与提示词、上下文压缩、会话清理和旧格式历史建立分组；各项控件列从同一位置开始，Shell 路径在选择器下方完整换行显示，短输入保持适当宽度。压缩阈值在 Slider 旁显示百分比。两类清理操作各自把状态放在按钮下方，说明文案收短，避免动作与结果失去关联。
- 日志：两项设置放入「日志记录」分组。关于：应用标识改为紧凑的横向排版，自动更新改用左标题右开关的标准行，去掉重复的行内标签和“即时生效”字样。
- 页内规则统一收口到 `settings-theme.css`；原 `app.css` 中仅服务这些页的网格、技能和关于样式删除。搜索用的 `data-setting-id`、注册表字段归属、草稿保存和即时生效语义保持原样。

## 手动验收

按仓库约定，界面改动由用户手动点验。在宽、窄窗口及浅、深主题下逐页检查分组标题、行分隔线、控件对齐和长文案；切换中英文，确认技能名称、路径与说明不会顶开右侧操作。切换技能开关、取消技能删除、修改写入后检查与压缩配置、运行清理预览、切换自动更新，并确认各项沿用原来的保存或即时生效方式。
